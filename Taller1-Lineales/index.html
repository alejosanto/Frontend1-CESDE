Taller 1 - Ejercicios Lineales

Ejercicios para aplicar fundamentos básicos de JavaScript mediante datos de entrada, operaciones y resultados.

Ejercicio 1

Salario neto: ingresar un salario, calcular el descuento del 4% de salud y 7% de pensión, y mostrar el salario final.

Ejercicio 2

Área de un triángulo: ingresar base y altura y calcular el área usando la fórmula (base × altura) / 2.

Ejercicio 3

Operaciones básicas: ingresar dos números y mostrar suma, resta, multiplicación, división y módulo.

Ejercicio 4

Salario mensual: calcular el pago de un trabajador a partir de horas trabajadas y valores de hora normal y extra.

Ejercicio 5

IVA: ingresar el precio de un producto, calcular el IVA del 19% y mostrar precio sin IVA, valor del IVA y total a pagar.

Ejercicio 6

Porcentaje de estudiantes: ingresar cantidad de hombres y mujeres y calcular qué porcentaje representa cada grupo.

Ejercicio 7

Promedio de notas: ingresar tres notas entre 1 y 5 y calcular el promedio.
