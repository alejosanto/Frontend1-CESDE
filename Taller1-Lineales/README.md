# Taller 1 - Ejercicios Lineales JS

Programación Web 1 - CESDE

Ejercicios realizados:

1. Cálculo de salario con descuentos de salud y pensión.
2. Área de un triángulo.
3. Operaciones básicas con dos números.
4. Cálculo del sueldo mensual con horas normales y extras.
5. Cálculo del IVA de un producto.
6. Porcentaje de alumnos y alumnas.
7. Promedio de tres notas.

Los ejercicios utilizan entrada de datos con `prompt()` y muestran los resultados en la consola con `console.log()`.
